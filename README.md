# Brew & Bloom Café - Promotion Page and HTML Email

A responsive promotional landing page and matching HTML email for a fictional café's spring offer.

## Files
- `index.html` - Landing page structure
- `style.css` - Layout and styling, including responsive media queries
- `script.js` - Form validation for the newsletter signup
- `email.html` - Table-based HTML email for the same campaign

## Technologies
- HTML5
- CSS (Flexbox, CSS Grid, media queries)
- JavaScript (form validation)
- HTML tables with inline CSS for email

## How to view
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Open `email.html` in a browser to preview the email layout.
